# Spiral Spruce (Fabric, Minecraft 26.3) - hanya untuk sapling
Sapling spruce 1x1 tumbuh jadi salah satu dari 6 pohon dari litematic (tinggi 17-36 blok), diputar acak.
Semua blok kayu spruce, daun spruce. Pohon alami di dunia tetap vanilla.

Build: JDK 25 + `./gradlew build` (salin gradle wrapper dari proyek lain) -> build/libs/spiral-spruce-1.0.0.jar
Tanpa setup: upload ke repo GitHub, tab Actions > build > unduh artifact.
Data pohon: PineData.java. Logika: PineModelFeature.java.
